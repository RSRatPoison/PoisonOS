# PoisonOS Roadmap

PoisonOS is an operating-system layer written entirely in Elixir. It runs on the
BEAM VM; a minimal boot layer (for example Nerves) can host it later. Everything
above that layer is Elixir.

Tasks are worked top to bottom, one per day. Add new `- [ ]` lines at any time.
Pure data-structure modules come first because they are the easiest to get right;
process-based modules follow.

- [x] Theme (`PoisonOS.Theme`): the colour palette as plain data. `colors()` returns the map `%{primary: "#00D000", highlight: "#28F030", shade: "#008000", accent: "#00A800", background: "#000000", text: "#E6E6E6", error: "#FF3B30", warning: "#FFC107"}`; `color(name)` returns `{:ok, hex_string}` or `:error`; `rgb(name)` returns `{:ok, {r, g, b}}` or `:error`.
- [x] Banner (`PoisonOS.Banner`): `logo()` returns the PoisonOS ASCII-art logo as a string of at most 12 lines, each at most 60 plain ASCII characters; `render(version)` returns `logo()`, a newline, then "PoisonOS " followed by the version string, all painted with `PoisonOS.Ansi.paint(text, :primary)`.
- [x] Shell prompt (`PoisonOS.Prompt`): `build(user, cwd)` returns the string "user@poisonos:cwd$ " with the user part painted `:primary` through `PoisonOS.Ansi.paint/2`; `build_plain(user, cwd)` returns the same string without any colour codes.
- [x] Scheduler (`PoisonOS.Scheduler`): a pure round-robin scheduler struct with new, enqueue, next, tick and remove
- [x] Memory manager (`PoisonOS.Memory`): a pure page-allocator simulation with new, alloc, free and stats
- [x] Virtual filesystem (`PoisonOS.FS`): an in-memory tree with mkdir, write, read, ls and rm as a pure data structure
- [x] Shell parser (`PoisonOS.Shell.Parser`): split a command line into a command and a list of args on spaces; text inside double quotes counts as one argument (no escapes, no single quotes). Use String.graphemes/1, not character literals
- [x] IPC (`PoisonOS.IPC`): message-passing mailboxes with send, receive and broadcast
- [x] Application supervisor (`PoisonOS.Application`): a supervision tree starting the core services, wired in mix.exs
- [x] Syscall layer (`PoisonOS.Syscall`): a plain-function facade over existing modules. `Syscall.new()` returns `%{fs: FS.new(), mem: Memory.new(16, 4096)}`; `Syscall.alloc(sys)` returns `{:ok, page, sys}` or `{:error, :no_memory}`; `Syscall.mem_stats(sys)` returns `Memory.stats(mem)` unchanged. Use only the existing public APIs.
- [x] Device driver manager (`PoisonOS.DeviceDriver`): load drivers with `load(driver_module)` returning `:ok` or `{:error, reason}`; list loaded drivers with `list()` returning `[module]`.
- [x] Network stack (`PoisonOS.Network`): send packets with `send(iface, packet)` returning `:ok`; receive packets with `receive(iface)` returning `{:ok, packet}` or `:empty`.
- [x] Logger (`PoisonOS.Logger`): log messages with `log(level, message)` returning `:ok`; retrieve recent logs with `recent(level, count)` returning `[message]`.
- [x] User manager (`PoisonOS.UserManager`): create users with `create(username, password)` returning `{:ok, user_id}`; authenticate with `auth(username, password)` returning `{:ok, user_id}` or `:error`.
- [x] Process table (`PoisonOS.ProcessTable`): use Agent; `start_link(opts)` accepts a `:name`. `register(table, name, pid, state)` returns `:ok` or `{:error, :exists}`; `lookup(table, name)` returns `{:ok, %{pid: pid, state: state}}` or `:error`; `update_state(table, name, state)` returns `:ok` or `:error`; `unregister(table, name)` returns `:ok`; `all(table)` returns a map of name to record
- [x] Scheduler enhancements (`PoisonOS.Scheduler.Priority`): priority queue scheduler with `new()`; `enqueue(sched, pid, priority)`; `next(sched)` returns `{:ok, pid}` or `:empty`.
- [x] Simple shell scripting (`PoisonOS.Shell.Script`): `run(script, fs)` parses lines separated by "\n", executes built-in commands via `PoisonOS.Shell`, returns {:ok, final_fs} or {:error, reason, fs}.
- [x] Device driver hot reload (`PoisonOS.DeviceDriver.HotReload`): `reload(driver_module)` unloads and loads a driver, returning :ok or {:error, reason}.
- [x] File permissions (`PoisonOS.FS.Permissions`): add permission structs to FS entries; `chmod(fs, path, mode)` returns {:ok, new_fs} or :error; `stat(fs, path)` returns {:ok, %{mode: mode, size: size}}.
- [x] IPC channels (`PoisonOS.IPC.Channel`): create named channels with `new(name)`; `send(chan, msg)` returns :ok; `receive(chan)` returns {:ok, msg} or :empty; `close(chan)` returns :ok.
- [x] Boot sequence (`PoisonOS.Boot`): ordered startup of services with logging
- [x] Virtual console (`PoisonOS.Console`): write text to a virtual console buffer with `write(console, string)` returning updated console; read the buffer with `read(console, count)` returning `{string, new_console}`.
- [x] Environment variables (`PoisonOS.Env`): manage per-process environment with `set(env, key, value)` returning updated env; `get(env, key)` returns `{:ok, value}` or `:error`; `delete(env, key)` returns updated env.
- [x] Process monitoring (`PoisonOS.ProcessMonitor`): start_link(opts) launches a GenServer that tracks process exits; `watch(monitor, pid)` returns :ok; `unwatch(monitor, pid)` returns :ok; `list(monitor)` returns [{pid, reason}] of terminated processes.
- [x] Simple package manager (`PoisonOS.Pkg`): install packages with `install(pkg_name, version)` returning `:ok` or `{:error, reason}`; list installed packages with `list()` returning `[{pkg_name, version}]`.
- [x] Signal handling (`PoisonOS.Signal`): register signal handlers with `register(pid, signal, fun)` returning `:ok`; send signals with `send(pid, signal)` returning `:ok` or `{:error, :noproc}`; list handlers with `list(pid)` returning `[{signal, fun}]`.
- [x] Path (`PoisonOS.Path`): path helpers. `split(path)` returns the list of non-empty segments, so `split("/usr//local/")` returns `["usr", "local"]`; `join(segments)` returns the absolute path string, so `join(["usr", "local"])` returns `"/usr/local"` and `join([])` returns `"/"`; `normalize(path)` resolves `.` and `..` and never goes above the root, so `normalize("/a/./b/../c")` returns `"/a/c"` and `normalize("/../a")` returns `"/a"`; `absolute(cwd, path)` returns `normalize(path)` if path starts with `/`, else `normalize(cwd <> "/" <> path)`.
- [x] Environment variables (`PoisonOS.Env`): `new()` returns an empty env; `put(env, key, value)` and `delete(env, key)` return the new env; `get(env, key)` returns `{:ok, value}` or `:error`; `expand(env, text)` replaces each `$NAME` (letters, digits and underscore) with its value, or an empty string if unset, and returns the string.
- [x] Pipe (`PoisonOS.Pipe`): a bounded byte buffer. `new(capacity)` takes a positive integer; `write(pipe, binary)` returns `{:ok, pipe}` or `{:error, :full}` if the data does not fit; `read(pipe, n)` returns `{data, pipe}` with up to n bytes in first-in first-out order (data may be an empty string); `size(pipe)` returns the number of bytes stored.
- [x] Timer queue (`PoisonOS.Timer`): `new()`; `schedule(timer, at, event)` returns the new timer, where at is a non-negative integer; `tick(timer, now)` returns `{events, timer}` with every event whose at is at most now, ordered by time and then by insertion; `pending(timer)` returns how many events remain.
- [x] Shell built-ins (`PoisonOS.Shell`): `exec(command, args, fs)` returns `{:ok, output_string, new_fs}` or `{:error, reason_string, fs}`. Supports echo (output is the args joined by one space), mkdir (output is an empty string), ls (output is the entry names joined by newlines) and cat (output is the file content), using the public functions of `PoisonOS.FS`. An unknown command returns `{:error, "unknown command", fs}`
- [x] Text buffer (`PoisonOS.TextBuffer`): `new(text)` splits text into lines; `insert(buf, line, col, text)` inserts a single-line string at zero-based line and column and returns `{:ok, buf}` or `{:error, :out_of_range}`; `delete_line(buf, line)` returns `{:ok, buf}` or `{:error, :out_of_range}`; `lines(buf)` returns the list of lines; `text(buf)` returns all lines joined by newlines.
- [x] Block device (`PoisonOS.BlockDevice`): an in-memory disk. `new(block_count, block_size)` takes positive integers and fills every block with zero bytes; `read_block(dev, n)` returns `{:ok, binary}` or `{:error, :out_of_range}`; `write_block(dev, n, data)` returns `{:ok, dev}`, `{:error, :out_of_range}`, or `{:error, :bad_size}` when `byte_size(data)` is not the block size.
- [x] ANSI styling (`PoisonOS.Ansi`): terminal colours using `PoisonOS.Theme.rgb/1`. `paint(text, name)` returns the text wrapped in a 24-bit ANSI foreground colour for the theme colour `name`, followed by the reset code, or the unchanged text if the name is unknown; `strip(text)` removes all ANSI escape sequences from a string.
- [x] Configuration manager (`PoisonOS.Config`): load configuration from a file with `load(path)` returning `{:ok, config}` or `{:error, reason}`; retrieve values with `get(config, key, default \\ nil)` returning `value` or `default`.
- [x] Event bus (`PoisonOS.EventBus`): publish events with `publish(event, payload)` returning `:ok`; subscribe with `subscribe(event, pid)` returning `:ok`; unsubscribe with `unsubscribe(event, pid)` returning `:ok`; receive events via messages `{:event, event, payload}`.
- [x] Expression evaluator (`PoisonOS.Expr`): `eval(string)` returns `{:ok, number}` or `{:error, reason_string}`. It supports integers, decimals, `+ - * /`, parentheses and unary minus, with the usual precedence. Division returns an integer when exact, otherwise a float; dividing by zero returns `{:error, "division by zero"}`; bad input returns `{:error, "syntax error"}`.
- [x] Simple HTTP client (`PoisonOS.HTTP`): `get(url)` returns `{:ok, status_code, headers, body}` or `{:error, reason}`; `post(url, body, headers \\ [])` returns same shape.
- [x] Clipboard history (`PoisonOS.Clipboard.History`): maintain a list of recent clipboard entries with `new(limit)`; `push(history, text)` adds entry, dropping oldest if limit exceeded; `list(history)` returns `[text]` in most-recent-first order.
- [x] Process signals (`PoisonOS.Signal`): register signal handlers with `register(pid, signal, fun)` returning `:ok`; send signals with `send(pid, signal)` returning `:ok` or `{:error, :noproc}`; list handlers with `list(pid)` returning `[{signal, fun}]`.
- [x] Process groups (`PoisonOS.ProcessGroup`): create groups with `new()`; add a pid with `add(group, pid)` returning updated group; remove a pid with `remove(group, pid)`; list members with `members(group)` returning `[pid]`.
- [x] Clipboard (`PoisonOS.Clipboard`): store a single string with `set(text)` and retrieve with `get()` returning `{:ok, text}` or `:empty`.
- [x] Permissions (`PoisonOS.Permissions`): `new()`; `grant(perms, user, path_prefix, action)` and `revoke(perms, user, path_prefix, action)` return the new perms, where action is `:read`, `:write` or `:exec`; `allowed?(perms, user, path, action)` returns true only if the user has a grant whose prefix covers the path on a whole-segment boundary, so a grant on `"/home/ann"` covers `"/home/ann/notes"` but not `"/home/annie"`.
- [x] Shell built-ins repair (`PoisonOS.Shell`): the built-ins currently call `PoisonOS.FS` with the wrong argument and return shapes, so mkdir, ls and cat do not work with a real filesystem. Rewrite `exec(command, args, fs)` so it works with `PoisonOS.FS.new()`. Paths arrive as strings; convert each with `PoisonOS.Path.split/1` before calling FS, which takes the path list first and the filesystem last (`FS.mkdir(path_list, fs)`, `FS.write(path_list, content, fs)`, `FS.read(path_list, fs)`, `FS.ls(path_list, fs)`, `FS.rm(path_list, fs)`). FS returns `{:ok, new_fs}`, `{:ok, entries}` or `{:ok, content}` on success and `{:error, reason_atom}` on failure. Keep `echo` and `run/2` as they are. Supported commands: `mkdir path`; `ls path` (no argument means "/"); `cat path`; `rm path`; `write path text` (the remaining args joined by one space become the file content); `touch path` (writes an empty file only if the path cannot be read). Success returns `{:ok, output_string, new_fs}` (output is an empty string for mkdir, write, rm and touch; ls output is the entry names joined by newlines). Failure returns `{:error, to_string(reason), fs}` with the original fs. An unknown command returns `{:error, "unknown command", fs}`. Tests must use `PoisonOS.FS.new()`.
- [x] Environment listing (`PoisonOS.Env`): add `to_list(env)` returning every variable as a list of `{key, value}` tuples sorted by key.
- [x] Basic commands (`PoisonOS.Command.Echo`, `PoisonOS.Command.Env`, `PoisonOS.Command.Set`, `PoisonOS.Command.Unset`, `PoisonOS.Command.Whoami`, `PoisonOS.Command.Calc`): implement the `PoisonOS.Command` behaviour. `Echo` outputs the args joined by one space. `Env` outputs `KEY=value` lines, one per variable, using `PoisonOS.Env.to_list/1`. `Set KEY value` stores the variable and `Unset KEY` removes it, both with an empty output. `Whoami` outputs `machine.user`. `Calc` joins the args with spaces and evaluates them with `PoisonOS.Expr.eval/1`; the output is the number as a string, and an error returns `{:error, reason_string, machine}`.
- [x] Process table (`PoisonOS.Procs`): a pure struct for simulated processes, using `PoisonOS.Scheduler` for ordering. `new()`. `spawn(procs, name, ticks, page)` returns `{pid, procs}`, where ticks is a positive integer, page is any term, and pids are integers starting at 1. `step(procs)` runs one scheduling step: it picks the next process in round-robin order, lowers its remaining ticks by one, and returns `{finished, procs}` where finished is the list of records `%{pid: pid, name: name, page: page}` of processes that reached zero ticks (those are removed). `kill(procs, pid)` returns `{:ok, record, procs}` or `{:error, :no_such_process}`. `list(procs)` returns records `%{pid: pid, name: name, left: left, page: page}` sorted by pid.
- [x] Accounts (`PoisonOS.Accounts`): pure user records. `new()` has no users. `add(accounts, name, password)` returns `{:ok, accounts}`, `{:error, :exists}`, or `{:error, :invalid_name}` when the name does not match `~r/^[a-z][a-z0-9_]*$/`. `check(accounts, name, password)` returns `:ok` or `:error`. `exists?(accounts, name)` returns a boolean. `names(accounts)` returns the sorted names. Never store the plain password: store `Base.encode16(:erlang.md5(name <> ":" <> password))`.
- [ ] Account commands (`PoisonOS.Command.Adduser`, `PoisonOS.Command.Su`): implement the `PoisonOS.Command` behaviour. `Adduser name password` uses `PoisonOS.Machine.add_user/3` and outputs an empty string; errors map to `{:error, "permission denied", machine}`, `{:error, "user exists", machine}` or `{:error, "invalid user name", machine}`. `Su name password` uses `PoisonOS.Machine.switch_user/3`; on failure it returns `{:error, "bad login", machine}`.
- [ ] Access guard (`PoisonOS.Guard`): `required(command, args, cwd)` returns a list of `{absolute_path, action}` for these commands only: `ls` (:read, the cwd when there is no argument), `cat` (:read), `cd` (:exec), `mkdir`, `touch` and `rm` (:write), `write` (:write on the first argument only), `cp` (:read on the first argument, :write on the second), `mv` (:write on both). Paths are made absolute with `PoisonOS.Path.absolute/2`; any other command returns `[]`. `check(machine, command, args)` returns `:ok` when `machine.user` is "root" or every required pair is allowed by `PoisonOS.Permissions.allowed?(machine.perms, machine.user, path, action)`, otherwise `{:error, "permission denied: " <> path}` for the first denied path.
- [ ] Guarded execution (`PoisonOS.Machine`): before running any single command inside `exec/2`, call `PoisonOS.Guard.check/3` with the parsed command and args; on `{:error, message}` return `{command <> ": " <> message, machine}` without running the command.
- [ ] Script runner (`PoisonOS.Machine`): add `run_script(machine, text)` returning `{output, machine}`. It splits the text on newlines, runs each line through `exec/2` in order (blank lines and lines starting with "#" produce no output), and joins the non-empty outputs with newlines.
- [ ] Source command (`PoisonOS.Command.Source`): implements the `PoisonOS.Command` behaviour. `Source path` reads the file (resolve the path, split it with `PoisonOS.Path.split/1`, read it with `PoisonOS.FS.read/2`) and runs its text with `PoisonOS.Machine.run_script/2`; the script output is the command output. A missing argument or unreadable file returns an error tuple with a short message.
- [ ] Interactive session (`PoisonOS.REPL`): `session(machine, lines)` runs the list of lines through `PoisonOS.Machine.exec/2` and returns `{transcript, machine}`. For each line the transcript gets `PoisonOS.Machine.prompt(machine)` followed by the line and a newline, then the output followed by a newline when the output is not empty. The line "exit" stops processing and is not run. `start()` runs a live loop on the terminal: print `PoisonOS.Banner.render("0.1.0")`, then repeat: print `PoisonOS.Prompt.build(user, cwd)`, read a line with `IO.gets/1`, stop on end of input or "exit", otherwise run it with `PoisonOS.Machine.exec/2` starting from `PoisonOS.Machine.new()` and print any output. Only `session/2` needs tests.
- [ ] Shell launcher (`Mix.Tasks.Poison.Shell`): a Mix task in lib/mix/tasks/poison.shell.ex using `use Mix.Task`, with `@shortdoc "Starts the PoisonOS shell"`. `run(_args)` calls `Mix.Task.run("app.start")` and then `PoisonOS.REPL.start()`.
- [ ] Snapshots (`PoisonOS.Snapshot`): `save(machine, path)` writes `:erlang.term_to_binary(machine)` to the host file at path with `File.write/2` and returns `:ok` or `{:error, reason}`. `load(path)` reads the file and returns `{:ok, machine}` using `:erlang.binary_to_term(binary, [:safe])`, or `{:error, reason}` when the file is missing or invalid.
- [ ] Snapshot commands (`PoisonOS.Command.Save`, `PoisonOS.Command.Load`): implement the `PoisonOS.Command` behaviour. `Save path` calls `PoisonOS.Snapshot.save/2` on the machine and outputs an empty string. `Load path` calls `PoisonOS.Snapshot.load/1` and returns `{:ok, "", loaded_machine}`, replacing the current machine. Failures return `{:error, to_string(reason), machine}`.
- [ ] Edit command (`PoisonOS.Command.Edit`): implements the `PoisonOS.Command` behaviour using `PoisonOS.TextBuffer`. `Edit path insert LINE TEXT...` and `Edit path delete LINE` read the file into a `PoisonOS.TextBuffer.new/1`, change it with `insert/4` (column 0, zero-based line) or `delete_line/2`, and write `PoisonOS.TextBuffer.text/1` back with `PoisonOS.FS.write/3`. LINE is a zero-based integer string parsed with `Integer.parse/1`. Failures such as an out-of-range line return `{:error, message, machine}`.
- [ ] Filesystem image (`PoisonOS.FSImage`): stores a filesystem on a `PoisonOS.BlockDevice`. `pack(fs, block_size)` serialises `:erlang.term_to_binary(fs)`, prefixes it with its byte size as a 32-bit big-endian integer, pads it with zero bytes to a multiple of block_size, and writes it block by block into a new `PoisonOS.BlockDevice.new(block_count, block_size)` using `write_block/3`; it returns the device. `unpack(device)` reads all blocks, uses the size prefix to cut the exact term bytes, and returns `{:ok, fs}` with `:erlang.binary_to_term(bytes, [:safe])`, or `{:error, :bad_image}` when the data is invalid.
- [ ] Time service (`PoisonOS.Time`): get current time with `now()` returning `%DateTime{}`; schedule a one-shot timer with `after(ms, fun)` returning a reference; cancel timer with `cancel(ref)` returning `:ok` or `{:error, :not_found}`.
- [ ] Disk quota manager (`PoisonOS.DiskQuota`): track usage per user with `new(limit_map)` where limit_map is `%{user => bytes}`; `charge(quota, user, bytes)` returns `{:ok, new_quota}` or `{:error, :exceeded}`; `available(quota, user)` returns remaining bytes.
- [ ] Simple DNS resolver (`PoisonOS.DNS`): resolve hostnames with `resolve(name)` returning `{:ok, ip}` or `{:error, :not_found}`; cache results internally.
- [ ] Machine state (`PoisonOS.Machine`): a pure struct that holds the whole system. Fields and defaults: `fs`, `mem`, `sched`, `env`, `cwd` ("/"), `user` ("root"), `perms`, `console`, `stdin` (empty string), `accounts` (nil), `procs` (nil). `new()` returns a machine with `fs` set to `PoisonOS.FS.new()` plus the directories /bin, /etc, /home and /tmp (create them with `PoisonOS.FS.mkdir/2`, which takes the path list first), `mem` set to `PoisonOS.Memory.new(64, 4096)`, `sched` to `PoisonOS.Scheduler.new()`, `env` to `PoisonOS.Env.new()`, `perms` to `PoisonOS.Permissions.new()` and `console` to `PoisonOS.Console.new()`. `resolve(machine, path)` returns `PoisonOS.Path.absolute(machine.cwd, path)`. `prompt(machine)` returns `PoisonOS.Prompt.build_plain(machine.user, machine.cwd)`.
- [ ] Command behaviour (`PoisonOS.Command`): defines `@callback run(args :: [String.t()], machine :: PoisonOS.Machine.t()) :: {:ok, String.t(), PoisonOS.Machine.t()} | {:error, String.t(), PoisonOS.Machine.t()}`. `lookup(name)` returns `{:ok, module}` when a module named `PoisonOS.Command.` followed by the capitalised name exists (build it with `Module.concat(PoisonOS.Command, Macro.camelize(name))`), is loaded (`Code.ensure_loaded?/1`) and exports `run/2`; otherwise it returns `:error`. `names()` returns the sorted list of lowercase command names for all loaded modules under `PoisonOS.Command` that export `run/2`; get the module list from `:application.get_key(:poison_os, :modules)`.
- [ ] Machine execution (`PoisonOS.Machine`): add `exec(machine, line)` returning `{output_string, new_machine}`. Trim the line; a blank line or a line starting with "#" returns `{"", machine}`. Otherwise expand variables with `PoisonOS.Env.expand(machine.env, line)`, parse with `PoisonOS.Shell.Parser.parse/1` (it returns `{command, args}`), and find the module with `PoisonOS.Command.lookup/1`. On `{:ok, output, machine}` return `{output, machine}`. On `{:error, message, machine}` return `{command <> ": " <> message, machine}`. An unknown command returns `{command <> ": command not found", machine}`.
- [ ] Filesystem commands, part 1 (`PoisonOS.Command.Pwd`, `PoisonOS.Command.Cd`, `PoisonOS.Command.Ls`): each module implements `run(args, machine)` of the `PoisonOS.Command` behaviour. Paths are resolved with `PoisonOS.Machine.resolve/2` and then split with `PoisonOS.Path.split/1` before calling `PoisonOS.FS`, which takes the path list first. `Pwd` returns the cwd as output. `Cd` with no argument goes to "/"; with one argument it checks that `FS.ls(path_list, machine.fs)` succeeds, then sets `cwd` to the resolved path and returns an empty output, otherwise it returns `{:error, "no such directory: " <> path, machine}`. `Ls` lists the given directory (the cwd if no argument) with the entry names sorted and joined by newlines.
- [ ] Filesystem commands, part 2 (`PoisonOS.Command.Cat`, `PoisonOS.Command.Mkdir`, `PoisonOS.Command.Touch`): implement the `PoisonOS.Command` behaviour. `Cat path` returns the file content as output. `Mkdir path` creates the directory and returns an empty output. `Touch path` writes an empty file only if the path cannot be read and returns an empty output. Resolve relative paths with `PoisonOS.Machine.resolve/2`, split with `PoisonOS.Path.split/1`, and update `machine.fs` with the result. A missing argument returns `{:error, "missing path", machine}`; an FS failure returns `{:error, to_string(reason), machine}`.
- [ ] Filesystem commands, part 3 (`PoisonOS.Command.Write`, `PoisonOS.Command.Rm`, `PoisonOS.Command.Cp`, `PoisonOS.Command.Mv`): implement the `PoisonOS.Command` behaviour with the same path handling as the other file commands. `Write path text` writes the remaining args joined by one space as the file content. `Rm path` removes a file or an empty directory. `Cp src dst` copies a file's content to dst. `Mv src dst` copies then removes the source. All return an empty output on success and `{:error, to_string(reason), machine}` on failure.
- [ ] System commands (`PoisonOS.Command.Free`, `PoisonOS.Command.Help`, `PoisonOS.Command.Clear`): implement the `PoisonOS.Command` behaviour. `Free` outputs three lines, `total: N`, `used: N` and `free: N`, in pages, from `PoisonOS.Memory.stats(machine.mem)`, which returns a map with the keys `total_pages`, `used` and `free`. `Help` outputs "Commands: " followed by the names from `PoisonOS.Command.names/0` joined by ", ". `Clear` outputs an empty string.
- [ ] Pipeline parsing (`PoisonOS.Shell.Pipeline`): pure string helpers that ignore characters inside double quotes. Use `String.graphemes/1`, not character literals. `stages(line)` splits the line on each "|" and returns the trimmed parts as a list of strings. `redirect(line)` returns `{command_part, nil}` when there is no redirection, otherwise `{command_part, {:write, path}}` for a trailing "> path" or `{command_part, {:append, path}}` for a trailing ">> path", with both parts trimmed.
- [ ] Pipes and redirection (`PoisonOS.Machine`): extend `exec(machine, line)`. Use `PoisonOS.Shell.Pipeline.redirect/1` on the whole line first, then `PoisonOS.Shell.Pipeline.stages/1` on the command part. Run the stages in order through the existing single-command logic; the output of each stage becomes the `stdin` field of the machine for the next stage (reset `stdin` to an empty string after the last stage). If a stage returns an error output, stop and return it. With a redirect, write the final output to the path (resolved with `resolve/2`, split with `PoisonOS.Path.split/1`) using `PoisonOS.FS.write/3`; for `:append` first read the existing content (an empty string if missing) and add the new output after it. A redirect returns `{"", machine}`, or the error text if the write fails.
- [ ] Text commands (`PoisonOS.Command.Head`, `PoisonOS.Command.Tail`, `PoisonOS.Command.Wc`, `PoisonOS.Command.Grep`, `PoisonOS.Command.Sort`): implement the `PoisonOS.Command` behaviour.
